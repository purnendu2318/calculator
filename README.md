## Overview

Neon Glass Scientific Calculator is a browser-based calculator with a modern glassmorphism interface. It combines everyday arithmetic with scientific functions, keyboard support, calculation history, and memory controls—all in a single-page application.

## Features

| Feature | Description |
|---|---|
| Basic arithmetic | Addition, subtraction, multiplication, division, and percentages |
| Scientific functions | Sine, cosine, tangent, logarithms, square root, powers, and factorial |
| Angle modes | Switch between degrees (DEG) and radians (RAD) |
| Calculation history | Review previous calculations and reuse expressions |
| Memory controls | Memory clear, recall, add, and subtract |
| Keyboard support | Enter calculations using your keyboard |
| Theme switcher | Toggle between dark and light themes |
| Responsive layout | Adapts to desktop and smaller screens |
| Modern interface | Glassmorphism styling, animated background, and button effects |

## Keyboard shortcuts

| Key | Action |
|---|---|
| `0–9` | Enter numbers |
| `+`, `-`, `*`, `/` | Arithmetic operators |
| `^` | Power |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last character |
| `Escape` | Clear the expression |
| `s` / `c` / `t` | Insert sin / cos / tan |
| `l` / `g` | Insert ln / log |
| `r` | Insert square root |
| `p` | Insert π |
| `a` | Insert the last answer |
| `d` | Toggle DEG / RAD |

## Getting started

No package installation or build tools are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/purnendu2318/calculator.git
   ```

2. Open the project folder:

   ```bash
   cd calculator
   ```

3. Open `index.html` in your browser.

You can also open the file directly from your file manager.

## Tech stack

- **HTML5** — application structure
- **CSS3** — responsive layout, themes, glassmorphism, and animations
- **Vanilla JavaScript** — expression parsing, calculations, keyboard events, history, and memory
